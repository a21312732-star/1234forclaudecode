# Канал ностальгии — «Проснулся в …»

Вертикальные шортсы 9:16 для YouTube: «Представь, что ты просыпаешься в 20XX». Целевая аудитория — 18–25 лет
(год ролика = их детство). Узнаваемые вещи эпохи без логотипов, настоящих людей и персонажей игр.
Петля: «А теперь закрой глаза и…» → «…представь, что ты просыпаешься…».

| Папка | Год | Возраст зрителя тогда |
|---|---|---|
| `2021/` | 2021 | 13 лет: поп-ит, симпл-димпл, стримы, «Игра в кальмара», кринж/краш, маска |
| `2019/` | 2019 | 11 лет: флосс, все качают новую игру, первый тикток, мем с волком и «ауф», кубики снова в моде |
| `2017/` | 2017 | 9 лет: спиннер, лизун, челленджи «100 слоёв», кубический дом, «Деспасито» |

- `common.js` — общая рисовка: спальня, календарь «машина времени», реквизит. Движок — `../survival/engine.js`.
- `voice-text.txt` в каждой папке — текст для озвучки (freetts.ru, Никита Калинин).
