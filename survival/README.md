# Серия «Выживи» — 2D-анимация про выживание

Вертикальные ролики 9:16 (YouTube Shorts + TikTok), ~45–50 с, закольцованы: последний кадр = первому,
последняя фраза обрывается и переходит в первую. Своя плоская рисовка (персонаж, сцены), звук синтезируется в браузере.

| # | Папка | Тема | Ролик |
|---|-------|------|-------|
| 1 | `01-led/` | Провалился под лёд | `01-led/01-led.mp4` |
| 2 | `02-metel/` | Застрял в метель в машине | `02-metel/02-metel.mp4` |
| 3 | `03-les/` | Заблудился в лесу | `03-les/03-les.mp4` |

- `engine.js`, `engine.css` — общий движок серии: персонаж с позами и эмоциями, субтитры, переходы, тряска, звук, плеер, экспорт.
  Ролик (`index.html`) задаёт только сцены, субтитры (`CAPS`), музыку (`MUSIC`) и эффекты (`SOUND`).
- В каждой папке: `SCENARIO.md` (текст для озвучки), `PUBLISH.md` (название, описание, хэштеги), `voice.mp3`.
- Сейчас озвучка черновая (синтезатор RHVoice). Своя озвучка или с сайта:

```bash
PROJECT=survival/01-led VOICE_FILE=путь/к/озвучке.mp3 PAUSE=0.15 SCENE_PAUSE=0.3 python3 tools/make-voice.py
```

```bash
node tools/export-mp4.js survival/01-led/01-led.mp4 survival/01-led
```

Черновик синтезатором:

```bash
RATE=128 TARGET_F0=128 PAUSE=0.16 SCENE_PAUSE=0.3 PROJECT=survival/01-led python3 tools/make-voice.py
```

## Правила серии

- Только проверенные советы из открытых рекомендаций спасательных служб; спорное — не утверждать.
- Хук в первую секунду, без приветствий. Вопрос в комменты в конце. Петля.
- В описании каждого ролика — напоминание: в опасной ситуации звонить 112.
